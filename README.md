# KELEPİR

2002 yılında Kavşak şehrinin Eskiyaka mahallesinde **0 ₺** ile başlayan web tabanlı ikinci el ticaret oyunu.

## İlk oynanabilir hedef

- 2002 başlangıç ekranı
- Eskiyaka'daki oda
- Odayı tıklayarak araştırma
- İlk eşya: Raksen RX-40 kasetçalar
- Ürünü inceleme ve temizleme
- Sonraki adım: çalışma testi, aileden izin alma, Cumartesi Pazarı ve ilk pazarlık

## Teknoloji

- Next.js
- React
- TypeScript
- Tailwind CSS

## Geliştirme

```bash
npm install
npm run dev
```

Tarayıcıda `http://localhost:3000` adresini aç.
